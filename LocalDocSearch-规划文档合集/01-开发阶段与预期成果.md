## 1. 项目目标

在 Windows 11 上提供一款独立桌面程序：指定文件夹后，搜索其子目录内 TXT、MD、DOCX、XLSX、PPTX、文字型 PDF、CSV、LOG 的**文件正文**，显示命中文件、全部匹配处、上下文和精确到格式允许的位置信息；支持单/多关键词、AND/OR 模式、文件类型筛选、打开文件、打开所在目录和尽可能直接跳转到匹配位置。

产品原则：**搜索准确性优先；不修改原始文件；默认离线；不要求 Office 才能检索 Office 文件；可取消、可排错、可维护；为大规模检索预留演进空间。** 用户已安装 Microsoft Office，可在当前环境验证 Office 精确定位，但公开版不能假定所有用户都安装 Office。

## 2. 版本边界

| 版本/阶段 | 优先级 | 必须交付的能力 | 明确暂不承诺的能力 |
|---|---|---|---|
| v0.1 原型 | P0 | 文本搜索、搜索结果与上下文、可运行 GUI | 所有格式齐全、安装包 |
| v0.2 格式闭环 | P0 | 8 种扩展名可检索；段落/单元格/幻灯片/页码等定位信息 | 旧版 `.doc/.xls/.ppt`、OCR |
| v0.3 交互闭环 | P0 | AND/OR、文件类型过滤、设置、双击定位回退、取消/错误列表 | 全格式无条件“光标精确跳转” |
| v0.4 稳定性与性能 | P0 | 自动化测试、性能基线、异常文件隔离、用户文档 | 百万级文件索引承诺 |
| v1.0 公开发布 | P0 | 源码、合规许可证、可安装版本、发布说明、可复现构建 | 跨平台、扫描件 OCR |
| v1.x 增强 | P1/P2 | 增量缓存、全文索引、大目录优化、正则等，依基准决定 | 具体上线时间不预先绑定 |

说明：以上为**能力里程碑**，不是日历日期。阶段是否结束，取决于验收结果；若关键技术验证失败，可调整实现路线而不是硬赶版本号。

## 3. 分阶段工作与可验收成果

### 阶段 0：需求冻结与技术风险验证（先做）

**工作**：
1. 固化搜索语义：默认普通文本匹配；多关键词通过 AND / OR 按钮选择；AND 指“同一文件内均出现”，不要求同段；后续再考虑独立的正则模式。
2. 固化格式边界：仅 `.txt .md .docx .xlsx .pptx .pdf .csv .log`；`.pdf` 仅可提取文字的文档，扫描件 OCR 不在 v1.0。
3. 制作含中文、重复命中、隐藏工作表、Word 表格、PPT 文本框/备注、文字型/扫描型 PDF、损坏/加密文档、大日志、不同编码的测试样本。
4. 做三个**技术验证实验（Spike）**：Office COM 直接定位的可靠性；候选 UI 框架的交互；Excel“显示值/公式”与 PDF 位置映射的可实现程度。
5. 审核预选第三方库的许可条款，选定项目 LICENSE 草案。

**交付物**：`docs/decision-log.md`（决策记录）、`tests/fixtures/`（可公开的虚构测试材料）、`docs/spike-results.md`（实验结果）、更新后的需求文档。

**验收**：确认哪种文件能定位到哪一级；未实现的内容不得伪装为已支持；预选技术栈有可运行的最小示例。

### 阶段 1：项目骨架与 TXT/MD/LOG 搜索原型

**工作**：建立分层项目、目录遍历、读取纯文本、字符/行号映射、取消机制、后台执行与 UI 搜索结果列表。

**交付物**：可运行 Windows 程序；按路径选择文件夹并检索 `.txt/.md/.log`；每个命中含文件路径、上下文、行号；可展开同一文件中的所有命中；最小单元测试。

**验收**：中文“西瓜”能命中；一个文件多次出现全部展示；搜索过程中界面可响应；取消后不再新增结果；单个损坏或无权限文件不会中断全局搜索。

### 阶段 2：多格式正文提取与统一位置模型

**工作**：接入 DOCX、XLSX、PPTX、文字型 PDF、CSV 的提取器；每段文本附带可解释的源位置信息；提供提取失败原因。

**交付物**：统一的 `TextSegment`/`SourceLocator` 契约、8 类文件适配器、样本基线测试、完整的匹配计数与位置标签。

**验收**：DOCX 正文/表格，XLSX 工作表/单元格，PPTX 幻灯片/文本框，PDF 页码，CSV 行/列在基准样本中可查；对于不能准确提供的位置显示“未知/仅页级定位”，不虚构位置；扫描型 PDF 明确提示“不含可提取文字”。

### 阶段 3：搜索交互、设置与打开定位

**工作**：多关键词 AND/OR、文件类型过滤、结果排序、关键词高亮、上下文配置、按文件类型配置搜索范围；抽象打开和定位能力，Office 优先精确跳转，不行则降级为打开文件和展示位置。

**交付物**：用户可完整操作的主界面、设置界面、Office COM 可选定位器、文件位置跳转回退、功能测试。

**验收**：`西瓜 AND 苹果` 在同一文件不同段落也命中；OR 任一词即可命中；过滤类型生效；更改提取范围后新搜索结果与配置一致；双击结果不会修改原文件；不能精确跳转时给出明确提示。

### 阶段 4：可靠性、安全和性能基线

**工作**：文件大小/数量测试，超大 LOG 流式读取，Office/PDF 异常文件、临时锁文件、目录循环、路径权限、长路径、中文路径、资源回收、响应性测试。记录冷启动和重复搜索时间、峰值内存、失败文件数。

**交付物**：自动测试报告、性能基线报告、已知限制清单、用户友好的错误诊断与日志策略。

**验收**：无已知 P0 缺陷；在定义的样本和测试机器上达到已批准的性能基线；搜索被取消或某个解析器异常时不会损坏索引或用户文件。性能数值应在有真实样本后确定，不凭空承诺固定“秒级搜索”。

### 阶段 5：开源发布 v1.0

**工作**：选择并核对许可证；检查第三方依赖及源码归属；编写中英文至少一份完善 README（中文优先）、贡献指南、隐私说明、安全报告方式、使用说明；自动构建并生成可安装/可解压版本；GitHub Releases 发布与版本标记。

**交付物**：公开 GitHub 仓库、源码与测试、`LICENSE`、第三方许可说明、`README.md`、`CONTRIBUTING.md`、`CHANGELOG.md`、release 安装包、SHA-256 校验值。

**验收**：干净 Windows 11 环境能安装并完成样本搜索；不安装 Office 时依然能搜索 `.docx/.xlsx/.pptx`，只是 Office 自动定位按能力降级；许可证和第三方归属已通过检查；发布制品可重复构建。

### 阶段 6：数据驱动的后续增强（不阻碍 v1.0）

选择条件与候选方向：

| 触发条件 | 可选增强 | 完成后验证 |
|---|---|---|
| 重复搜索慢、解析占主要耗时 | 按文件修改时间/大小维护可失效的提取缓存 | 修改或删除文件后结果不陈旧 |
| 文件量明显增长、扫描成瓶颈 | 索引引擎 + 增量更新 | 中文 1/2/3 字查询无漏报（最终原文验证） |
| 用户需要高级表达式 | 独立“正则模式”+ 超时/取消/安全限制 | 不影响普通文本语义 |
| 需要扫描件/图片内文本 | OCR 可选插件 | OCR 结果显式标识置信度与来源 |
| 需要多系统 | 抽换 UI 层/平台定位层，Avalonia 等 | Windows 功能不回退 |
| 需要 `.doc/.xls/.ppt` | 独立旧格式适配器或安全转换 | 不要求静默打开宏或执行脚本 |

## 4. 重要依赖与决策关口

- **D1｜UI 框架（阶段 0 末）**：WPF、Avalonia、WinUI 3 选择其一；跨平台“以后再说”，但不要让 UI 与搜索引擎混杂。
- **D2｜Office 定位（阶段 0/3）**：验证精确跳转的边界；以“能力表 + 回退”发布，不承诺任意阅读器统一定位。
- **D3｜字段内容范围（阶段 2）**：对 Word 页眉/批注、Excel 公式/隐藏工作表、PPT 备注逐项标记“已支持/实验性/待实现”。
- **D4｜搜索加速（阶段 4/6）**：以性能报告决定是否进入 v1.0；不能为了索引牺牲中文短词和结果正确性。
- **D5｜开源许可证（阶段 0 初选，阶段 5 定稿）**：MIT 与 Apache-2.0 可重点讨论；仅查看 GPL 项目的设计，不复制不兼容代码进入宽松许可项目。

## 6. “完成”的统一定义（Definition of Done）

每个功能须同时具备：**可运行代码、至少一项自动测试、用户可理解的失败反馈、与文档一致的能力声明、无未经核实的隐私或许可证风险**。如果能力依赖用户安装 Office，必须在 UI 与文档中标明；如果只是显示定位信息，不允许写成“已经精确跳转”。

## 7. 当前已确认 / 待决定

**已确认**：Windows 11；独立桌面软件；8 类扩展名；AND/OR 按钮；结果上下文及文件元数据；逐格式搜索范围选项；双击定位且允许合理回退；支持自适应性能演进；项目完全开源；开发者当前安装 Microsoft Office。

**待决定**：WPF/Avalonia 等 UI；许可证 MIT/Apache-2.0；是否增加可切换的区分大小写选项；是否将 Word 页眉/Excel 公式/PPT 备注纳入 v1.0 的强制验收；缓存与索引何时实施；Office COM 直接定位的可验证程度。
