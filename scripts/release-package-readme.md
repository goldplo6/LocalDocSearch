# LocalDocSearch — Windows x64 本地候选

这是普通目录式自包含便携包，随包提供所需 .NET 运行时。完整解压后运行同目录的 `DocSearch.exe`；保留周围 DLL、运行时、docs 和许可证文件，不要只复制 EXE。无需另外安装 .NET，无需 Office 即可搜索或查看只读文字预览。目标环境为 Windows 11 x64，实际干净机器及 360 验证状态见下文边界。

## 校验与开始

交付 ZIP 附有同目录 `SHA256SUMS.txt`。解压前使用 PowerShell 的 `Get-FileHash <ZIP路径> -Algorithm SHA256` 比较摘要；解压后的 `file-manifest.json` 记录逐文件哈希。`build-record.json` 记录本包实际版本、SDK、运行时、源/候选锁哈希及自动化测试计数。

启动后选择一个有权读取的文档目录，添加关键词并开始搜索。支持 TXT、MD、LOG、CSV、DOCX、XLSX、PPTX 和文字型 PDF；匹配为字面量子串，AND/OR 按文件判断。源文档保持只读，不启动 Office 做提取。点击“定位并选中”打开重新核验来源的只读文字预览；它展示提取文字，PDF 不重建原版面，Word 的结构段落号不是打印页码。复杂 Office 区域和无文字 PDF 有能力边界，未实现 OCR。

界面按清爽专业设计 Demo 调整为独立品牌栏、搜索卡片和结果工具栏，采用白色表面、浅灰背景与蓝色主搜索按钮。结果卡片以格式徽标、文件名、匹配数、路径和摘要分层；预览操作保留“定位并选中”的含义，在宽度至少 1100 DIP 的主窗口中打开右侧预览，窄窗口打开独立预览。侧栏可关闭或弹出，缩窄窗口会转为独立预览；关闭侧栏恢复结果宽度。打开原文件、原文件查找、目录定位等低频动作位于对应文件或匹配行的更多操作菜单。应用内标识、窗口和 EXE 使用同一原创蓝色文档放大镜图标；ICO 包含从 16 到 256 像素的九个尺寸。

点击顶部“高级搜索…”进入“逻辑搜索”或“正则匹配”页。逻辑页提供可视化和手写公式两种编辑方式；应用后回主窗口点击“开始搜索”，取消保留原查询。公式可复制，说明默认折叠，错误在输入旁提示。

- 可视化：勾选同层相邻项，组成 AND/OR 组；可继续嵌套、取消括号、修改连接或删除词/整组。新增字面量可加入根层或所选组，重复词保留独立位置。主窗口和可视化新增框的 AND、OR、括号保持文字含义。待添加输入会阻止应用，避免丢词。
- 手写公式：例如 `西瓜 AND (苹果 OR 荔枝)`。AND 优先于 OR，连接须显式书写；含空格、括号或运算符的文字用双引号，如 `"AND" OR "苹果 香蕉"`。支持 `\"`、`\\`、`\n`、`\r`、`\t`、`\uXXXX` 转义。无效公式显示错误位置并阻止应用；修正后可返回可视化继续编辑，显示与执行使用同一表达式树。
- 正则匹配：使用 .NET 正则语法，例如 `[A-Z]\d{2}\b`；此模式独立于逻辑词表。对单个提取片段匹配，保留整体命中的真实文字与来源，跳过零长度命中，不拼接独立段落/页面/单元格。模式错误阻止应用；默认模式长度上限 4096，单次匹配预算 100ms、单文件累计匹配预算 1000ms，超时文件记录资源问题并丢弃该文件结果。预算和取消存在检查粒度。

搜索期间暂时禁用高级搜索编辑。点击“暂停”后，程序在协作检查点暂停扫描，并处理已接收的完整结果，再显示“已暂停”；此时点击“继续”接着本轮搜索。“停止”在运行或暂停期间都可用，保留已展示的完整文件结果；结束后可重新搜索。第三方同步解析和单次正则调用需返回检查点后才响应，暂停与停止不是强制挂起或终止线程。关键词、表达式树、手写内容和正则模式不保存到偏好文件。

为限制密集命中时的文本保留量，默认每文件结果上限为 16,777,216 个 UTF-16 字符，全局为 33,554,432 个，包含命中文字及两侧上下文。单文件预算在分配子串前检查，全局预算在完整文件发布前检查。文件超限会整文件丢弃并记录资源问题；全局超限会停止并保留此前完整文件。预览提取在进程内串行，排队可取消，仍完整检查来源。上述预算不包含对象开销、当前待发布文件或第三方解析器的全部内存，不是进程硬内存上限。

若本包构建时启用了样本，`samples/mixed` 为原创八格式样本，两词“西瓜”“苹果”应得 8 文件、16 处；`samples/long-documents` 的“长文定位西瓜”应得 4 文件、8 处，“长文末尾定位”应得 4 文件、4 处。长样本是定位与重复词验证材料，不代表大字节性能结果；Word 打印页数会受字体与环境影响。启动参数 `--settings <独立文件路径>` 可用于隔离试用设置。

## 当前交付边界

这是本地 release candidate，不表示公开发布 v1.0.0。候选未签名，操作系统/杀毒产品可能显示提示；干净机器、真实 360、中文 IME、多 DPI/键盘及完整外部 Office/阅读器矩阵仍应分别验收。遇到拦截保留版本与哈希反馈维护者，保持现有系统防护设置。搜索使用普通用户权限，不需要服务或驱动。
