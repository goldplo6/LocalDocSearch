## 对齐内容

- 将品牌栏、搜索卡片和结果工具栏分开，恢复 Demo 的白色表面、浅灰背景、蓝色主操作与间距节奏；最小窗口使用紧凑布局，未打开预览时结果区域仍至少占整窗面积 60%。
- 文件结果补齐格式徽标、清晰的文件名/数量/路径层级与自定义展开外观；主操作保持突出，低频命令继续放在更多菜单。
- 高级搜索使用真正的蓝色下划线页签、统一的模式切换、公式区、代码编辑区和固定操作栏，保留可视化、手写逻辑、正则的真实校验和草稿保护。
- 预览沿用真实提取文字与来源校验，用分隔线、来源卡片和白色正文区贴近 Demo；不根据示例内容伪造原文排版。
- 原创图标采用蓝底、折角文档与放大镜，提供 SVG、PNG 与多尺寸 ICO；接入应用内品牌标识、窗口图标和 EXE 资源。

1. 参照 Demo 实际 CSS 和现有布局，确定差异与可保留的行为边界。
2. 分别完成主窗口、高级窗口、共享主题/预览和图标资源，并读回代码。
3. 运行桌面完整回归与新增 Demo 对齐测试；使用独立构建目录，保留既有成品。
4. 完整构建并制作新的自包含候选；独立解压验证高级搜索、分组、结果面积、响应式预览、300 文档滚轮及图标资源。
