# 第二阶段：八格式提取与可核对的来源位置

状态：六项工作包已实施并完成自动回归及真实窗口基本操作验证（2026-11-09），详见[第二阶段报告](phase-2-results.md)。承接第一阶段文本原型；第一阶段 IME、多 DPI、完整键盘与真实滚动的专项人工验收仍保留在原报告。

## 目标与边界

在 Avalonia 原型上支持 TXT / MD / LOG / CSV / DOCX / XLSX / PPTX / 文字型 PDF，使用统一 TextSegment 与 SourceLocator。关键词依旧为字面量连续子串，每个词独立非重叠计数；AND/OR 在文件级判断，可跨不同段落、单元格和页面。不同来源片段之间不拼接出并不存在的短语，同段落的连续文本 run 合并后匹配。

搜索只读、离线，不启动 Office、不执行公式、不获取外部关系内容。打开文件仍为默认程序打开，明确显示“仅打开文件”；精确 COM 定位、阅读器页码参数、OCR、索引/缓存、持久配置、安装包不在本阶段交付内。

## 格式语义

- TXT/MD/LOG：严格 UTF-8 或 BOM 指明的 UTF-8/16/32；按物理行分段，行列从 1 开始，列为 UTF-16 单元。传统编码后续补充。
- CSV：包含表头在内的所有字段可搜索；CRLF/CR 在字段内规范化为 LF。逻辑记录、字段编号从 1 开始，不尝试推断分隔符或列类型。
- Word：正文段落与正文表格中的段落；run 合并，跨段落/单元格不拼接。页眉/页脚/批注/文本框暂未支持，段落编号是解析结构位置，非排版页码。
- Excel：可见普通工作表。共享/内联字符串、布尔值、原始数字/错误值以及有缓存的公式结果；来源标注原始值/公式缓存。不重算，不承诺还原格式化显示。隐藏表、公式源码、批注不进入默认范围；无公式缓存应警告，不能当成可靠的无命中。
- PowerPoint：按 SlideIdList 定义的演示顺序；幻灯片文本框与表格的段落，附对象提示。备注、批注和组合图形暂未支持。
- PDF：页面内提取顺序与视觉顺序可能不同，多栏/断行影响短语；只报告提取文字中的命中。

本阶段范围开关使用固定能力声明，未实现的区域不提供假开关。持久化逐格式设置留待第三阶段，完整 v1.0 验收仍以 SRS 为准。

## 依赖与测试

官方 NuGet 索引本机查询后固定 DocumentFormat.OpenXml 3.5.1、PdfPig 0.1.16，中央版本与锁文件纳入构建。许可分别按包元数据核对；此处不代表完整分发许可审查已通过。

自动回归包括八格式基线、CSV 跨行/转义/晚失败、跨单元格不造词、跨段文件级 AND、来源页序、隐藏表与公式缓存、损坏文件隔离、取消和读取前后哈希/修改时间。使用原创临时夹具和可重建样本，不依赖 Office 安装。同步第三方解析的单次调用可能延迟取消；超大文件、超长片段与海量结果的内存压力仍须阶段四实测。
