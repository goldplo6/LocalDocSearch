## 本轮定点修复

[主窗口输入处理](../src/LocalDocSearch.Desktop/MainWindow.axaml.cs)在 Enter 添加前检查当前 TextBox 内 TextPresenter 的非空 PreeditText；[高级窗口 Esc](../src/LocalDocSearch.Desktop/QueryGroupingWindow.axaml.cs)对当前焦点 TextBox 做相同局部检查，避免预编辑仍在时提交词或关闭窗口。普通 Enter/Esc 原有行为保留。检查只读当前输入控件，不使用反射或全局键盘钩子。

依据为 Avalonia 12.1.5 [TextBox 的组合态分支](https://github.com/AvaloniaUI/Avalonia/blob/12.1.5/src/Avalonia.Controls/TextBox.cs#L1398-L1408)和[输入客户端写入 PreeditText](https://github.com/AvaloniaUI/Avalonia/blob/12.1.5/src/Avalonia.Controls/TextBoxTextInputMethodClient.cs#L145-L155)。框架组合态分支直接返回而没有将事件标为 Handled，应用自己的处理器需保留组合态。原处理只接受 Key.Enter，Key.ImeProcessed/Key.None 本来就被排除，没有另加重复条件。

该证据证明控件组合态下的应用行为，不证明所有 Windows 输入法都按同样的按键顺序发出事件。测试没有更改系统输入法、缩放、服务、Hosts、阅读器或杀毒设置。

## 距正式发布还剩几阶段

当前高级搜索阶段已完成；紧接着的交互阶段已完成本机可执行的自动化，环境收尾仍有缺口。按当前实际交付顺序，正式发布前还剩 **两段收尾**：

1. **真实环境专项验收**：完成上表 Windows IME、原生多屏 DPI、干净机/无 Office 与用户目标环境，修复复现的问题并对变更做对应回归。
2. **正式版发布准备与分发验收**：结合环境结论确定正式版本，核对许可、说明、候选完整性、签名/分发方案；实际公开仓库、push、签名与远程发布仍按用户后续指令执行。

本轮已完成上述第二段的本地准备子集：13 项目无警告构建、909 项测试、自带 .NET 10.0.14、30 个 NuGet 许可与运行时 NOTICE、稳定 ZIP/哈希/清单、独立解压运行、路径漏扫、源与产物前后完整性。该准备不等于环境验收或正式公开发布。已有[发布指南](release-guide.md)、[隐私说明](privacy.md)及[安全说明](security.md)可供审阅。

原路线图的 0—4 阶段已交付，5 阶段本地候选已具备、公开发布收尾未完成，6 阶段按需增强已加入本次高级搜索。缓存、索引、OCR、旧格式或跨平台仍按需求与测量另行决定，不另算成正式版必经阶段。
