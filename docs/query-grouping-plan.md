# 可视化括号分组实施计划

日期：2026-11-12。状态：已完成；在已验收的本地候选 1.0.0-rc.2（689 项测试）基础上交付 1.0.0-rc.3（752 项全通过），并通过独立解压的真实分组、布局与滚轮验收。本阶段是查询能力的小步扩展，不代表性能优化、公开发布或完整跨平台验收已完成。

## 目标

直接构造 `A AND (B OR C)` 及嵌套分组，使屏幕显示的公式与搜索引擎的整文件资格判断使用同一棵表达式树。关键词继续按普通文字匹配；输入框中的 `AND`、`OR`、括号不解析为公式。

## 工作包

1. **核心表达式模型**：增加词位置、二元 AND/OR、显式分组节点；旧请求的相邻连接转换成树。保留旧请求构造兼容、大小写比较、重复文字去重提取、跨片段整文件资格、资源和取消语义。
2. **可视化编辑器**：在紧凑主窗口打开专用编辑窗口；草稿支持同层相邻节点分组、嵌套、取消分组、删除、连接修改与重复词。应用才修改主查询，取消保留原查询。
3. **边界检查**：词数和字长沿用查询预算；表达式最多 128 层、256 个节点。每个原输入位置恰好引用一次；无效节点、空子节点、错误运算符、越界或重复引用、遗漏词在文件访问之前报错。不得同时提交显式树和相邻连接。
4. **回归与真实窗口**：核心真值表、重复文字、无效树；桌面编辑、取消、删除、超限和真实文件结果。保留末项展开、回收、50 条分页及结果面积回归；用自有窗口、临时语料和独立设置验证实际分组操作和搜索。
5. **本地候选交付**：在独立白名单源码快照中完整构建、测试、打包新候选，保留 rc.2；核验 ZIP、清单、运行时、源码输入以及运行前后文件不变。更新使用说明、变更记录及验收报告。

## 交互与语义约束

- 编辑器提供明确的公式预览与分组边界，避免手写语法错误。
- AND 优先于 OR，显式括号改变计算顺序；取消分组后以当前父层连接重新解释，并立即显示新公式。
- 重复关键词以独立位置身份编辑，提取时相同文字仍只匹配一次；树的叶位置映射回真实匹配结果。
- 搜索运行期间禁止修改查询；关键词、表达式树和源文件正文均不新增持久化。
- 原文件自动填词继续停止调试，不操作 Adobe 窗口、服务、Hosts 或杀软设置。
- 不进行 git commit/push、签名或远程公开发布。中文输入法、完整键盘、多 DPI 与干净机验收仍单独列为待办，不以本地脚本替代。
