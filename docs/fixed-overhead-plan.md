## 方案取舍

| 建议 | 现状与决定 | 验证方式 |
| --- | --- | --- |
| Excel 地址去 Regex／子串分配 | 采纳；使用 Span 检查 ASCII 形状，保留原 `int.TryParse` 文化和失败输出 | 旧算法独立差分、边界／文化／实际工作簿、坐标微基准 |
| 多词候选集延迟创建 | 采纳；32 个不同词以上，只在首次遇到至少 256 字符片段时建立一次线程安全共享候选集 | 1／2／4 工作者与 0／255／256 字符回归；32／64 词短行对照 |
| 重用命中定位 | 小范围采纳；仅物理文本行原位置的列号已等于命中列号时复用不可变记录，其余仍复制正确列号 | 字面量／正则、多列命中、原位置不变及既有预览来源核验 |
| 减少文件元数据检查 | 暂缓；多个 FileInfo getter 已共享缓存。枚举属性是较早缓存，替换 fresh 分类会改变删除、reparse 和失败计数时序；提前文件基线也会改变 progress 回调／排队期间改源的结果 | 保留发现时分类、文件开始快照、完整 EOF 后复核，含无命中文件 |
| 匹配包装对象懒建 | 既有实现已按 50 条分页，并非全量包装；本轮保留第一页和回收展开行为 | 完整 Desktop 与既有滚动／预览回归 |
| CSV 块解析／每行结构调整 | 暂缓。文本和 CSV 已块读；CSV 可疑成本是逐字符异步调用链，而不是每字符磁盘 I/O。批量状态机与公共行 ID／定位结构须另行测量和边界设计 | 不把推测计作本轮收益 |

## 验收顺序

1. 定向回归：候选创建阈值及共享、定位列号、Excel 坐标差分和基准工具边界。
2. 同驱动、只替换 Core／Extractors 两个库的 ABBA 交替：坐标 50 万次、5 个原搜索场景、短行 16／32／64 词及长行无命中 32／64 词，各版本每场景 6 个计时样本。正文内容与顺序摘要单独核验，不放在计时回调中。
3. 完整锁定依赖构建和六套测试，再构建自带运行时的 rc.10 本地候选；保留旧可执行文件与 ZIP。
4. 从候选解压目录启动自有窗口，验证少／多关键词、AND／OR 和只读预览、实际包内运行时、源文件不变与正常退出。
5. 独立核对 ZIP／构建记录、当前源码与锁文件、测量二进制、文档链接及排敏感结果；记录负收益和未覆盖环境。

## 边界

无新增依赖、索引、跨次正文缓存或 OCR，默认仍单工作者。累计分配、CPU、耗时和进程寿命峰值分别报告；坐标微基准不等同于 XLSX 或所有文档端到端加速。协作暂停／取消和 Office/PDF 同步解析的限制、逻辑资源预算非硬 RSS 上限、源文件非一致快照等现有边界保留。

实测结果见[验收报告](fixed-overhead-results.md)：保留坐标和密集结果的分配收益，明确多小文件未确认提速、大日志的小幅负收益与紧邻交替复测；初测和最终包测量不混算。
