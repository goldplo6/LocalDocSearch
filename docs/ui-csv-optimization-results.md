# UI 首屏与 CSV 块解析优化结果

日期：2026-11-15。状态：实现、完整回归、最终包对照及四类原生验收已通过；独立审计结果保存在本地候选目录的 `final-audit.json`。

基线为已验收的 rc.10。实现范围和取舍见[计划](ui-csv-optimization-plan.md)，原建议见[优化机会评审](performance-opportunities-review.md)。沿用离线只读、默认单工作者、每轮提取与搜索，不增加索引、跨轮正文缓存或依赖。本轮不提交或推送。

## 实现与正确性

- 文件结果构造时不创建匹配行包装。首次 `IsExpanded=true` 时加载至多 50 条；程序展开、提前 LoadMore、收起重开与虚拟化回收保留已加载页及包装引用。摘要直接读取原始首条匹配。
- 原始 `MatchItem` 及其上下文仍全部保留。这一项减少折叠状态下的包装对象和集合通知，不等于消除结果数据内存。
- CSV 保留 8192 字符缓冲，字符处理改为同步 `TryRead`，只在缓冲耗尽时异步补充。CR 先完成原始下一字符预读，再产出归一化 LF，保留跨块解码失败和终端 CR 后 EOF 的原时序。
- 保留字段 ID、记录／字段／来源行号、引号及空字段规则、错误文字、逐字段预算、逐字符取消与错误文件整体丢弃。主窗口主动展开滚动 guard、双层虚拟化和末页禁用占位保持。

13 个项目构建为 0 警告、0 错误；六套测试共 **1665 项全部通过、0 跳过**：Core 879、Desktop 178、Extractors 231、Navigation 191、Settings 37、Benchmarks 149。新增 45 项 CSV 差分、9 项懒加载、3 项滚动与 47 项基准工具测试，共 104 项。192 组生成 CSV 的内部差分循环不另算测试项。

CSV 测试保留独立旧算法参考，比较完整片段、异常前已产出前缀、异常类型和文字；覆盖 8191／8192／8193 附近 CRLF、CR、引号、代理对、编码失败、预算、取消与晚段失败。UI 覆盖构造零包装、预加载、程序展开、50／100 条回收及末页滚轮可达。

## CSV 与引擎最终包对照

[测量脚本](../scripts/measure-csv-parsing.ps1) 使用同一个新驱动，仅替换实际 rc.10／rc.11 包中的 `LocalDocSearch.Core.dll`，其余文件逐项 SHA256 相等。原创普通、引号、跨块 CSV 各 8 MiB，分别做直接提取、稀疏命中与无命中，共九场景；另保留小文件和混合格式引擎对照。

按 old／new／new／old 串行，每组每场景三轮，每版本每场景六个计时样本：44 组进程、132 个性能样本、108 次计时外 CSV 完整验证与 8 次引擎独立摘要验证。全部内容、顺序、来源、计数、问题及源文件前后戳等价。原始记录：`artifacts/csv-parsing-measurement-7e0ffefd2498439a88a8749e3be1fcf3/summary.json`。

负号代表耗时减少。纯文本小文件对照不经过 CSV 或界面包装路径，其变化不归因为本轮算法收益。直接提取包含 I/O、解码和解析，不是纯解析时间；未清 OS 缓存，不称冷启动。每轮计时后另做完整提取与搜索摘要，摘要时间排除。

普通 CSV 另用相同实际包和驱动做紧邻 ABBA 补测，原主矩阵保持原字节，补测不混算：12 组、36 个性能样本及 36 次计时外完整验证。直接提取 156.4387→144.0194 ms（约 -7.94%）；稀疏命中 149.7763→163.7965 ms（约 **+9.36%**）；无命中 142.4684→153.2542 ms（约 **+7.57%**）。记录为 `artifacts/csv-plain-supplement-bf4cae2a87a640bf88cbee02ab7a2680/summary.json`。稀疏命中回退重现，无命中结论随样本变化；保留这些代价，不宣称所有 CSV 搜索提速。

累计分配略减：直接普通 21,561,368→21,117,320 bytes；直接引号 19,122,800→19,053,468；直接跨块 17,444,616→17,352,308。其他六个 CSV 场景也有小幅减少。CPU 不保证同向，例如主矩阵普通无命中 156.25→171.875 ms。全部 CPU、分配及峰值原始数组保存在报告；进程寿命峰值包含前面轮次的验证，不是单轮独立内存峰值，也不是硬 RAM 上限。

## 最终包原生验收

- CSV：两有效文件 9 处命中，逐条核记录／字段／起始行、只读字段全文与应用选区反馈；9 次预览加首次侧栏主动弹出共 10 次。晚段坏文件为 Partial／InvalidData，完整文件结果丢弃且精确错误可见。报告 `artifacts/ui-csv-uia-6e189bcde5e54bedbb6f68d4449c783a/results.json`。
- 普通查询：七种 32／8／4／2 词、AND／OR、重叠与 Unicode 场景及只读预览。报告 `artifacts/literal-prefilter-uia-fe6fd784dced44e093daf2fb5fd7cf86/results.json`。
- 真实滚轮：300 文件／369 匹配，166 次局部滚轮；末文件前 50 条、再加载 70 条均可达，真回收后仍展开且末条可见（回收阶段 73 次滚轮）。报告 `artifacts/result-wheel-8fd82a9dc3ab4746b5b272b34d5e6f80/results.json`。
- 控制：默认 1 工作者的暂停／继续、暂停后停止、运行中停止及结果保留共四场景。报告 `artifacts/concurrency-controls-uia-961feb35d65841f69c720bc63df18330/results.json`。

四类均针对同一包，源文件 SHA256／长度／mtime 不变，正常关闭自有进程；CSV 与查询预览运行时来自包内。UIA 的 TextPattern 不可用时，证据是 Value 全文加应用内部 SelectedText 反馈，不声称独立原生选区验证。未启动原文件，未继续调试 Acrobat。

## 交付与复测

候选为 `artifacts/releases-ui-csv/LocalDocSearch-1.0.0-rc.11-win-x64/`，内层同名目录含 `DocSearch.exe`；ZIP 与内层目录同级。自带 win-x64 .NET 10.0.14，354 个包文件。ZIP SHA256：


[独立审计脚本](../scripts/verify-ui-csv-optimization.ps1) 核六套真实 TRX、源码与快照、13 个锁文件、包清单、实际库哈希、原始测量、24 个进程身份、四类原生证据及文档链接；旧 rc.10／rc.9 包和原运行目录保留。根目录“启动最新版.cmd”仅将启动入口指向 rc.11，不覆盖旧运行目录。

可复用[CSV 原生工具](../scripts/verify-ui-csv-uia.ps1)、[普通查询工具](../scripts/verify-literal-prefilter-uia.ps1)、[控制工具](../scripts/experiments/verify-concurrency-controls-uia.ps1)与本地 `artifacts/history/tools/verify-result-wheel.ps1`。最终审计拒绝覆盖已存在的 `final-audit.json`，复测需新候选目录，不将历史终审覆盖为新结果。

发现分类、文件初始长度／mtime 与完整 EOF 后来源复核保持，仍不构成一致性快照。第三方 Office／PDF 同步解析、真实中文 IME／跨屏 DPI、干净机器与正式签名分发仍沿用既有边界。缓存、索引、OCR、Excel 去重策略与纯文本专用扫描均留待独立设计和测量。
