# 隐私与本地数据

适用于当前 LocalDocSearch 本地候选。搜索、Office/PDF 文字提取和只读匹配预览在本地进程中执行，当前应用代码没有联网搜索服务、账户登录、自动上传、遥测或自动诊断日志。安装开发 SDK、首次 NuGet 还原和手动 CI 是独立的开发操作，需要访问对应下载服务，不属于应用搜索流量。

## 数据如何使用

用户选定的目录、文件路径、关键词、提取文字、匹配片段和错误提示在搜索/预览期间用于内存中的结果与状态显示。搜索和只读预览不保存或改写源文档，也不创建搜索索引、全文缓存或历史记录。用户主动请求“默认程序打开”“在文件夹中显示”或原程序定位时，路径会交给 Windows 和相应外部应用；这些程序的网络、最近文件、缓存及隐私行为由其自身管理。

用户显式保存偏好时，默认文件为 `%LOCALAPPDATA%\LocalDocSearch\settings.json`，包括搜索根目录、文件类型、AND/OR、大小写、编码、上下文字数、排序、文档范围和 Office 自动化开关。**根目录可能包含个人信息**。偏好不保存关键词、正文或搜索结果。损坏/无效配置使用默认值并显示提示，原配置保留至用户显式保存。启动参数 `--settings <文件路径>` 可为验证指定独立配置，避免改动日常设置。

“复制诊断摘要”仅在用户主动点击后写入系统剪贴板，包含聚合计数、耗时、资源预算、运行时、操作系统和处理器/架构信息；排除目录、文件路径、关键词、正文及异常原文。结果复制、截图以及手动分享的文件仍可能含个人信息，分享前应自行检查。剪贴板同步、操作系统崩溃转储、交换文件及外部阅读器记录不由本应用控制，因此本地处理不等于磁盘上绝无相关系统痕迹。

## 清理与交付

退出应用会释放应用内存中的结果；清理本地偏好可在退出后移除上述设置文件，之后启动使用默认值。设置路径是用户数据，请先确认自己要保留的偏好。便携包解压目录可整体移除；这不会自动清理用户设置或外部程序记录。

候选 ZIP 只包含发布输出、说明、许可证与可选原创样本，不打包个人设置、搜索内容、开发缓存、构建日志或 TRX。构建机内部验证目录可能含机器路径，应留在本地；对外分享优先使用 ZIP 和对应 SHA256。
