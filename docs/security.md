# 安全说明与候选验证

本项目当前提供本地候选构建。已执行的自动化结果和人工验证须以对应版本的构建记录为证；没有公开安全认证、干净机器全矩阵验证或真实 360 兼容性认证。默认 SDK/NuGet 下载、应用运行、外部程序打开与杀毒产品检查是不同环节，应分别记录结果。

## 获取和运行

候选是普通 Windows x64 自包含目录 ZIP。先从可信的项目交付渠道取得 ZIP 和 `SHA256SUMS.txt`，使用 `Get-FileHash <ZIP> -Algorithm SHA256` 比对摘要，再完整解压，运行 `DocSearch.exe`（rc.7 起；旧候选为 `LocalDocSearch.Desktop.exe`）。摘要用于核对传输完整性；与 ZIP 同渠道获得的摘要并不替代发布者身份签名。候选默认未进行 Authenticode 签名，Windows 或杀毒产品可能显示未知发布者、声誉或内容提示。

遇到拦截时先停止运行，保留 ZIP 哈希、产品/病毒库版本、提示内容及时间，交由项目维护者核查文件和复现。不要因此关闭防护、添加排除、调整系统信任设置或提升权限。应用正常搜索以普通用户权限运行，使用用户本来可读取的目录。便携交付不需要安装服务、驱动、计划任务或系统级 PATH 修改。

## 文档处理边界

默认搜索和只读预览只读取源文件；可选原程序定位会调用系统关联应用，Office 自动化默认关闭。解析器处理用户选定的文档，损坏、共享修改、解码错误和资源超限会分别报告。已有大小、片段、匹配、遍历及诊断预算是资源治理措施，不是第三方解析器隔离沙箱或进程整体内存硬限；某些同步调用可能延迟取消。

对来源不明的文档，保留 Windows、Office 和阅读器的现有保护设置。不要把本地搜索视为恶意文档检测器。应用不执行文档宏；外部程序自身的行为、插件与网络访问属于其独立边界。

## 维护与问题报告

当前没有配置公开仓库、专用安全邮箱或漏洞平台。请通过实际与你交付项目的维护者私下报告，附候选版本、ZIP SHA256、Windows 架构、最小原创复现和必要的聚合诊断摘要；先清除私人文档、关键词、路径、凭据与截图中的个人信息。不要把报告发给文档中不存在的地址。

依赖更新需复验源锁和候选 RID 锁、包内容哈希、许可证全文与原生/运行时 NOTICE，重新构建和测试。手动 CI 只上传候选产物，不自动创建公开发布。正式发布还需单独决策签名、信任渠道、依赖漏洞检查及实机验收，其完成状态应写入该版本的验收记录。

隐私行为见 [隐私说明](privacy.md)，构建与验收操作见 [发布指南](release-guide.md)。
