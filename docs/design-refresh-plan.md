# 清爽专业桌面界面实施计划

日期：2026-11-12。状态：已完成。用户已批准[独立设计 Demo](../artifacts/history/ui/ui-design-demo/index.html)，本阶段已将其视觉层级落实到 Avalonia 桌面程序。基于 rc.4 的 909 项回归，rc.5 现已通过 927 项完整测试、独立解压实窗及响应预览四场景。交付与证据见[验收报告](design-refresh-results.md)。

## 设计与范围

- 浅灰背景、白色内容区、蓝色主搜索操作，统一字号、圆角和边框；命中文字采用柔和黄色强调。
- 主窗口压缩工具区，将文件名、匹配数、路径和摘要分层；低频文件操作收进更多菜单。默认未打开预览时，结果区至少占窗口面积 60%。
- 宽度至少 1100 DIP 时按需打开右侧文字预览；窄窗口使用独立预览窗。关闭恢复结果宽度，缩窄可转到独立窗。共享组件重新提取并核对实际来源、读回选区，取消或更换请求后丢弃过期加载。
- 高级搜索保留逻辑/正则双页、可视化/手写、实际公式与草稿保护；说明折叠、错误就近显示、底部应用操作固定。
- 设置沿用统一主题。Demo 中示意的排序/密度/浏览器正则实现不作为本轮新增功能；现有设置中的排序能力继续保留。

## 工作包

1. 统一应用主题与共享预览组件，保留独立预览公共接口。
2. 主窗口与结果项改版，保留全部搜索命令、辅助操作和 UIA 入口。
3. 高级窗口视觉层级、帮助局部滚动和小窗口适配。
4. 桌面全量回归及新增预览异步生命周期、响应布局验证；全套构建后制作独立 rc.5 自包含候选。
5. 解压候选核验高级搜索、分组、结果面积、预览与 300 文档滚动，最后更新交付报告与摘要。

## 回归要求

保持两层虚拟化、50 条分页、末页“加载更多”的禁用占位、展开状态及主动展开的一次定位；不增加常驻滚动定位。保留真实 TextBox 组合输入的 Enter/Esc 护栏、Tab 与多行行为以及 100/125/150/200% 合成缩放测试。新主题不依赖新 NuGet 包。

仅交付本地候选，不提交或推送代码，不签名或公开发布。原文件自动填词继续停止调试。系统中文输入法、原生跨屏 DPI、干净机/无 Office、360 环境和正式分发验收仍按[输入环境矩阵](input-environment-results.md)单独记录。
