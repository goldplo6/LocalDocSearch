# DocSearch 使用

适用请求：查找某个文件夹里包含指定文字的文档，按多个条件筛选文件，或定位原文中的匹配内容。

## 操作步骤

1. 确定用户给出的文件夹、关键词和格式范围。只在该范围中操作。
2. 在用户指定的运行包目录启动 `DocSearch.exe`。若使用源码仓库，在仓库根目录运行：

   ```powershell
   ./scripts/bootstrap-sdk.ps1
   ./scripts/dev.ps1 -Action Run -Locked
   ```

3. 通过可用的桌面操作工具选择搜索文件夹、格式和大小写选项，再选择查询方式：
   - 普通搜索：逐个添加字面关键词，选择 AND／OR 连接。
   - 逻辑搜索：打开“高级搜索”→“逻辑搜索”，可视化分组或选择“手写公式”。例如 `西瓜 AND (苹果 OR 荔枝)`；含空格或运算符的文字用双引号括起。
   - 正则匹配：打开“高级搜索”→“正则匹配”，例如 `PRJ-\d{4}`。该模式独立于逻辑公式。
4. 高级搜索点击“应用条件”，回到主窗口核对实际查询，再开始搜索。长任务可暂停／继续；停止后保留已显示的完整文件结果。
5. 展开文件结果，查看匹配文字与来源位置，打开只读文字预览核对上下文。需要时打开原文件或所在目录。
6. 根据实际结果汇报命中文件数、匹配数、相关路径和位置；同时说明界面报告的跳过、警告或未完成状态。仅启动应用时，应如实说明当前进度。

## 使用要点

- AND／OR 在同一文件内判断；正则按提取片段匹配，独立段、页和单元格不拼接。
- 文本默认使用 Unicode；遇到 GB18030 文件，在设置中选择对应编码模式。
- 搜索为本地只读，每轮重新读取文件；图片文字和扫描型 PDF 需先做 OCR。
- 界面没有承诺的功能不作为既有能力：例如全文索引、跨次全文缓存、搜索命令行参数或结果导出接口。
- 预览中的命中位置与外部应用的原文件定位分别核对。原文件查找辅助按界面实际反馈记录结果。
